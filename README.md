# Crescimento Insta

Dashboard web para acompanhar métricas de crescimento do Instagram (seguidores, engajamento, posts).

## Stack

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vite.dev/)
- [Supabase](https://supabase.com/) (banco de dados e autenticação na nuvem)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Variáveis de ambiente

Copie `.env.example` para `.env.local` e preencha com as credenciais do seu projeto Supabase:

```bash
cp .env.example .env.local
```
